📦 Паттерн 1: готовые почты (просто и быстро)

Заголовок раздела «📦 Паттерн 1: готовые почты (просто и быстро)»

Самый простой путь — купить пакет почт у проверенного поставщика и сразу использовать. Никаких настроек, никакой переадресации.

Где брать: KYC SHOP by NVS — пакеты firstmail / notletters с готовым логином и паролем для IMAP.

Как подключить:

  1. Купить пакет почт в шопе
  2. В таблице AutoPilot заполнить только три столбца:
    • [EMAIL] mail = адрес почты из пакета
    • [EMAIL] mail_password = пароль из пакета
    • [EMAIL] mail_provider = firstmail / notletters
  3. Готово — переадресация не нужна, AutoPilot читает IMAP напрямую

💡 Подходит для большинства задач — KYC на любой бирже, верификация email, регистрации.

🍎 Паттерн 2: iCloud-ферма

Заголовок раздела «🍎 Паттерн 2: iCloud-ферма»

Альтернатива для тех, кто строит масштабную ферму. Использует Hide My Email от iCloud+ — один основной inbox принимает почту с тысячи sub-адресов.

ПлюсыМинусы
🟢 0.99$/мес → до 1000 hidden email адресов❌ Нужен iPhone для активации iCloud+
🟢 Все письма приходят на один основной inbox — читаете один IMAP вместо 1000❌ Apple ограничивает скорость создания (обход — hidemyemail-generator)
🟢 Apple подписывает домены — anti-spam, anti-detection
🟢 Особенно стабильно работает с Bybit

Как настроить:

  1. Купить iPhone + оформить подписку iCloud+ на icloud.com/icloudplus
  2. iCloud → Hide My Email → создать новые адреса (вручную или скриптом)
  3. Все hidden emails автоматически переадресуются на основной iCloud
  4. App-Specific Password для основной почты — support.apple.com/ru-ru/102654
  5. В таблице AutoPilot заполнить:
    • [EMAIL] mail = hidden_xxxx@icloud.com (один из 1000)
    • [EMAIL] mail_provider = icloud
    • [EMAIL] forwarding_mail = ваш основной main@icloud.com
    • [EMAIL] forwarding_mail_password = App-Specific Password основной почты
    • [EMAIL] mail_forwarding_provider = icloud

Удаление адресов и ротация («крутить» ферму заново):

Слоты под новые адреса можно освобождать, но с оговорками (проверено по Apple Support):

  1. Удалять можно только деактивированные адреса — сначала Deactivate, потом Delete. На icloud.com/icloudplus → Hide My Email → адрес → Deactivate, затем внизу списка под «N inactive addresses» → Delete address.
  2. Удаление необратимо: старый адрес назад не вернуть и не переиспользовать — при пересоздании Apple выдаёт новый случайный адрес.
  3. Удаление освобождает слот: на лимите Apple прямо пишет «delete one before creating another» — удалил → можешь создать новый.
  4. Не бесконечно и не мгновенно. Apple душит скорость: ~5 новых адресов / 30 мин (× число членов семьи), при упоре — кулдаун ~30–60 мин. Мягкий потолок ~500–1000 адресов на аккаунт.

⚙️ Что делает AutoPilot сам. Встроенный HME-генератор (pure-HTTP, без браузера) создаёт и резервирует адреса с учётом лимитов Apple (5/30 мин, авто-кулдаун на 429). Удаление — пока вручную на icloud.com. То есть «крутить» ферму = удалил вручную → AutoPilot догенерит новые.

📨 Паттерн 3: Outlook / Hotmail через refresh-token

Заголовок раздела «📨 Паттерн 3: Outlook / Hotmail через refresh-token»

Microsoft с 2024 отключил Basic Auth для IMAP на личных Outlook/Hotmail-аккаунтах — пароль почты сам по себе больше не подходит. Работает только OAuth2 с refresh-токеном.

Селлеры почт (например, KYC SHOP by NVS) продают Hotmail-комбо в формате:

Из всех полей AutoPilot нужны только два: email и последний длинный токен (начинается с M.).

Как подключить:

  1. Купить пакет Hotmail-комбо в шопе
  2. В таблице AutoPilot заполнить три столбца:
    • [EMAIL] mail = name@hotmail.com (первое поле комбо)
    • [EMAIL] mail_password = M.C510_BAY... (последнее поле — refresh-token, не обычный пароль)
    • [EMAIL] mail_provider = outlook
  3. Готово — AutoPilot сам определит, что это refresh-токен (по префиксу M.), обменяет его на access-токен через Microsoft и подключится к IMAP по XOAUTH2

🔄 Автообновление: access-токен живёт ~1 час, AutoPilot сам обновляет его в фоне без участия пилота.

💡 Обычный пароль тоже работает для аккаунтов, где Basic Auth ещё не отключён (старые корпоративные / forwarding-почты). Если пароль не начинается с M. — используется классический IMAP с логином/паролем.

2. 🔐 2FA: как это устроено

Заголовок раздела «2. 🔐 2FA: как это устроено»
  • При подключении 2FA софт сохраняет секретный ключ в столбец [2FA] totp_secret_code
  • Этот ключ можно импортировать в любое приложение: Google Authenticator, Authy, 1Password и др.
  • AutoPilot автоматически генерирует и вводит TOTP-коды при необходимости
  • Для ручной генерации кода из секретного ключа: totp.danhersam.com

💾 Бэкап: totp_secret_code дополнительно сохраняется в логи профиля (папка /logs) — даже если случайно очистите таблицу, секретный ключ всегда можно найти в логах.

⚡ Автоподключение: действия whitelist и withdraw автоматически подключат 2FA, если он ещё не установлен. Отдельно запускать 2fa не нужно.

⏰ 2FA коды не подходят? TOTP-коды зависят от точного времени на компьютере. Если код отклоняется биржей — синхронизируйте часы: Windows: Settings → Time & Language → Date & time → Sync now. macOS: System Settings → General → Date & Time → Set time and date automatically.

🌐 Bybit: проблемы с 2FA? Если код на почту не приходит при подключении Google Authenticator — укажите bybitglobal в столбце [BYBIT] domain таблицы. В ряде регионов bybitglobal.com работает стабильнее. Подробнее — Bybit AutoPilot → Bybit Global домены.

🖱️ Smart Cursor (MEDIUM/SLOW): имитирует человеческие движения мыши с рандомной траекторией, ускорениями и замедлениями.

⌨️ Human Typing (MEDIUM/SLOW): случайные задержки между символами, случайные опечатки с автоисправлением — как настоящий человек.

💡 Рекомендация: для регистрации и логина достаточно FAST. Для трейдинга и действий на страницах с антибот-защитой — MEDIUM.

4. 🧩 Прокси и капча

Заголовок раздела «4. 🧩 Прокси и капча»

Столбец [PROXY] proxy — прокси профиля в формате ip:port:user:password

✅ Заполнять не нужно — AutoPilot автоматически берёт прокси из вашего профиля AdsPower / Dolphin / Vision / Afina на лету. Капча решается с IP профиля, чтобы он совпадал с IP остального трафика. Всё происходит автоматически.

🏠 Прокси обязан быть резидентским. Встроенный решатель отправляет проверку капчи с IP профиля, а GeeTest не пропускает датацентровые IP — проверка не проходит. Дешёвый датацентровый прокси = стабильные падения на капче, даже когда всё остальное настроено верно.

🔄 Авторотация: зеркала Bybit и сессии прокси

Заголовок раздела «🔄 Авторотация: зеркала Bybit и сессии прокси»

Иногда регистрация упирается не в аккаунт, а в то, откуда вы пришли: биржа смотрит на репутацию выходного IP, и если с этого адреса уже создавали много аккаунтов, отказ придёт ещё до кода подтверждения. AutoPilot разбирается с этим сам — в два шага.

Шаг 1 — другое зеркало Bybit. Bybit это несколько доменов, и у каждого своя защита на входе. Тот же самый IP, которому отказал основной домен, часто спокойно проходит на bybitglobal.com. Раньше пилоты подставляли этот домен вручную — теперь AutoPilot перебирает зеркала сам:

📌 Рабочее зеркало запоминается. Домены Bybit — отдельные биржи с отдельными пулами аккаунтов: аккаунт, созданный на bybitglobal.com, на bybit.com не существует. Поэтому AutoPilot записывает сработавшее зеркало в столбец [BYBIT] domain, и все следующие действия по профилю идут туда же. Подставлять его руками больше не нужно.

Шаг 2 — свежая сессия прокси. Если зеркала закончились, дело всё-таки в адресе. У резидентских прокси номер сессии зашит в логине:

Меняется только номер сессии — и вы получаете свежий IP в той же стране. Страну AutoPilot не трогает никогда: иначе аккаунт молча уехал бы в другую гео.

Режим запускаЧто происходит
⚡ AutoPilot EngineБерёт свежую сессию и доводит регистрацию до конца сам — до 3 попыток, без вашего участия
🌐 Антидетект-браузерПрокси принадлежит профилю AdsPower / Dolphin / Vision / Afina, поэтому AutoPilot пишет в лог готовый логин с новой сессией

Провайдеры с поддержкой ротации: NodeMaven, Proxyshard, DataImpulse, Bright Data.

⚡ Как это работает: AutoPilot всегда сначала пробует решить капчу сам и обращается к платному провайдеру, только если попался редкий тип, который встроенный решатель пока не берёт. Большинство капч на Bybit, MEXC и Bitget закрыто — за них вы не платите вообще.

🚀 captcha_key больше не обязателен. Без ключа AutoPilot нормально стартует и работает — при запуске просто напишет предупреждение, что платная подстраховка отключена. Раньше пустой или обнулённый баланс вешал запуск намертво; в свежих версиях этого нет.

💰 Стоимость: у провайдера ~$1 за 1000 решений GeeTest, но платите вы только за те капчи, которые не взял встроенный решатель — тратится баланс на редкие типы, а не на каждый вход.

🔧 Ошибки капчи — что делать:

  • Сначала проверьте прокси. Датацентровый IP роняет и встроенный решатель, и платный. Нужен резидентский.
  • Если в логе видно, что AutoPilot ушёл к платному провайдеру, — вам попался редкий тип. Добавьте captcha_key от capsolver / capmonster / 2captcha.
  • Если капча падает до обращения к провайдеру — пополнение баланса не поможет, дело не в деньгах. Проверьте прокси и обновите AutoPilot.
  • Ключ должен быть от capsolver, capmonster или 2captcha — только они умеют token-based GeeTest v4. С ключом другого сервиса подстраховки не будет.

➕ Цепочки действий: несколько ACTION за один проход

Заголовок раздела «➕ Цепочки действий: несколько ACTION за один проход»

В ячейку ACTION можно записать не одно действие, а целый сценарий — шаги через +:

Шаги выполняются по очереди на каждом аккаунте. Аккаунты при этом по-прежнему идут параллельно (parallel_limit) — очерёдность действует только внутри одного аккаунта.

Зачем это нужно:

  • Раньше, чтобы прогнать три действия на одних и тех же аккаунтах, приходилось запускать батч три раза подряд, каждый раз дожидаясь окончания и заново отмечая профили
  • Браузер профиля не перезапускается между шагами — одна сессия на всю цепочку вместо трёх запусков антидетект-профиля

Настройки в конфиге:

КлючПо умолчаниюЧто делает
combo_action_delay30,120Случайная пауза в секундах между двумя шагами одного аккаунта. Меньше — быстрее, больше — меньше похоже на бота
combo_keep_browserYESОдин браузер на всю цепочку. Поставьте NO, если нужен чистый запуск профиля на каждом шаге

⚠️ Если шаг завершился ошибкой, оставшиеся шаги этого аккаунта пропускаются. Остальные аккаунты продолжают работать.

📝 Пробелы вокруг + не важны, регистр тоже: Register + Learn = register+learn. Если хотя бы один шаг цепочки написан с опечаткой или недоступен на вашем тарифе — строка не будет выбрана целиком.

6.1 🤖 Умная фьючерсная торговля (futures_smart)

Заголовок раздела «6.1 🤖 Умная фьючерсная торговля (futures_smart)»

ACTION: futures_smart — автоматическая торговля фьючерсами с анализом рынка, лимитными post-only ордерами и управлением позициями.

💰 Комиссии: post-only лимитные ордера = 0.02% (maker), закрытие по маркету = 0.055% (taker). Итого ~0.075% за цикл — на 32% дешевле чем маркет ордера (0.11%).

📊 Столбцы таблицы:

СтолбецОписаниеПример
[TRADING] trading_coinМонета для фьючерсовBTC
[TRADING] trading_amountРазмер позиции за одну итерацию (с учётом плеча) в USDT1000
[TRADING] trading_cyclesКоличество торговых циклов15

🔑 Важно: trading_amount — это размер позиции с учётом плеча, а не сумма реально используемого баланса. Реальный баланс на одну сделку = trading_amount / leverage.

📐 Формула:

  • Реальный баланс за сделку = trading_amount ÷ плечо
  • Объём за цикл = trading_amount × 2 (открытие + закрытие)
  • Целевой объём = trading_amount × cycles × 2

Пример: trading_amount=1000, leverage=10, cycles=15

  • Реальный баланс за сделку: 1000 ÷ 10 = 100 USDT
  • Объём за один цикл: 1000 × 2 = 2000 USDT
  • Целевой объём: 1000 × 15 × 2 = 30 000 USDT

⚙️ Параметры конфига:

ПараметрОписаниеПо умолчанию
leverage📊 Кредитное плечо10
limit_futures_position_hold_interval⏳ Время удержания позиции, сек (мин,макс)50,240
limit_futures_iteration_wait_interval💤 Пауза между циклами, сек (мин,макс)60,180
limit_futures_order_timeout⏱️ Макс. ожидание заполнения лимитного ордера, сек30
limit_futures_order_check_interval🔍 Интервал проверки исполнения ордера, сек5
limit_futures_price_offset_ticks📐 Отступ в тиках от лучшей bid/ask цены2
limit_futures_direction_algorithm🧠 Алгоритм определения направленияinverse_simple
limit_futures_order_deviation🎲 Случайное отклонение размера позиции, % (0 = выкл)0

🧠 Алгоритмы определения направления:

  • simple — следует за трендом: анализ последних 5 свечей + цена vs MA5 (рост → Long, падение → Short)
  • inverse_simple — контр-тренд: инвертирует сигнал simple (рост → Short, падение → Long)
  • advanced — комплексный анализ: EMA 8/21 кроссовер + RSI 14 + Volume Spike (1.7x от среднего) + Funding Rate

⚠️ Риски: фьючерсная торговля с плечом сопряжена с риском ликвидации. Используйте умеренное плечо и небольшие суммы для набива объёма.

💡 Совет: если ордер не заполняется в течение limit_futures_order_timeout — сигнал пересчитывается заново. Увеличьте limit_futures_price_offset_ticks для более быстрого заполнения (но с менее выгодной ценой).

7.1. 🔑 Мастер-кошелёк — Авто-whitelist, $0 комиссий, неотслеживаемый вывод

Заголовок раздела «7.1. 🔑 Мастер-кошелёк — Авто-whitelist, $0 комиссий, неотслеживаемый вывод»

Выводите с сотен аккаунтов не вводя ни одного адреса вручную. AutoPilot создаёт уникальный кошелёк для каждого аккаунта, сам добавляет его в whitelist, выводит с нулевой комиссией и собирает всё на ваш мастер-кошелёк. Каждый аккаунт выводит на свой адрес — связать их между собой невозможно.

Что вы получаете:

  • 🏷️ Автоматические вайтлисты — не нужно создавать адреса или заполнять таблицу. AutoPilot создаёт уникальный адрес для каждого аккаунта и добавляет его в whitelist на Bybit с полным подтверждением email/2FA
  • 🕵️ Неотслеживаемые выводы — каждый аккаунт выводит на свой уникальный адрес. Общего адреса нет = связать ваши аккаунты невозможно
  • 💰 $0 комиссия за вывод — Bybit не берёт плату за вывод в сети Aptos (против $1-2 за аккаунт на ERC20/TRC20)
  • 📥 Сбор в один клик — после вывода собираете все средства на мастер-кошелёк за секунды
  • ⚡ Мгновенные переводы — средства приходят за ~1 секунду

Как это работает (3 действия):

  1. setup_aptos_hd — запускается один раз. Создаёт ваш мастер-кошелёк и даёт секретную фразу (12 слов). Одна фраза = неограниченное количество адресов.

  2. whitelist_aptos_hd — запускается на всех профилях. AutoPilot сам:

    • Создаёт уникальный Aptos-адрес для каждого аккаунта
    • Заходит на Bybit, добавляет его в whitelist, подтверждает email/2FA — всё автоматически
    • Сохраняет всё в таблицу

  3. withdraw — выводит USDT на whitelisted адрес каждого аккаунта. Комиссия = $0.

8. 🌐 AdsPower / Dolphin / Vision / Afina

Заголовок раздела «8. 🌐 AdsPower / Dolphin / Vision / Afina»

🔀 Как AutoPilot выбирает антидетект-браузер

Переключателя браузера в AutoPilot нет. Антик выбирается сам — по тому, как выглядит [PROFILE] profile_id в таблице. Правила идут сверху вниз, работает первое подходящее:

УсловиеБраузер
в конфиге задан vision_configVision (перекрывает всё остальное)
profile_id — UUID (8e308a06-f9fd-4927-...) и в конфиге есть afina_api_keyAfina
profile_id — только цифры (1274563)Dolphin
profile_id — буквы и цифры (k1b0tidb)AdsPower

💡 Антики можно смешивать в одной таблице. Браузер выбирается для каждой строки отдельно, так что в одном запуске могут идти профили и AdsPower, и Dolphin, и Afina. AutoPilot перед стартом проверит, что все нужные программы запущены, и будет крутить профили параллельно — сколько сразу, задаёт parallel_limit.

С Vision так не выйдет: vision_config задаётся один раз на весь конфиг и проверяется первым, поэтому на Vision уедут все профили из таблицы.

⚠️ Частая проблема: перепутали «Номер» и «ID». В AdsPower два разных идентификатора: «Номер» — порядковый, только цифры, и «ID» — буквы с цифрами, например k1b0tidb. Скопировали «Номер» — AutoPilot видит одни цифры и идёт в Dolphin. Отсюда и ошибка Dolphin local server offline - Launch Dolphin then retry у человека, который Dolphin вообще не ставил. Нужна колонка ID.

⚠️ Ещё одна проблема: Afina без ключа. Для Afina нужны оба условия сразу — UUID в profile_id и afina_api_key в конфиге. Без ключа строка не подходит ни под одно правило (UUID не проходит проверку «буквы и цифры» из-за дефисов), и профиль уходит в AdsPower. Получите ошибку AdsPower про профиль, которого там нет. Проверьте afina_api_key в конфиге.

AdsPower:

  • 📥 Установите свежую версию SunBrowser: Настройки → Локальные настройки
  • 💳 Требуется платная подписка (минимум Base)
  • 📤 Экспорт профилей: Выделите → Экспортировать → Номер, ID, Имя. В таблицу AutoPilot идёт ID (k1b0tidb), НЕ «Номер» — иначе профиль уедет в Dolphin (см. выше)
  • 🔌 Порт API по умолчанию: 50325 (настраивается в конфиге adspower_port)
  • ⚠️ Обязательно отключите «API verification» (API & MCP → API Settings). Если тумблер включён, каждый запрос к локальному API требует ключ, и AutoPilot не сможет запускать и останавливать профили. Тумблер должен быть выключен:

Dolphin:

  • Включите Profile ID: Шестерёнка → Customize columns → Profile ID
  • ▶️ Приложение Dolphin Anty должно быть запущено, и вы должны быть залогинены — AutoPilot управляет профилями через локальный API (порт 3001). Для автоматизации нужна активная платная подписка (на free-плане запуск профилей через API недоступен).
  • 🔑 Обязательно укажите в конфиге свой токен: dolphin_key=ВАШ_API_ТОКЕН. Без него AutoPilot не сможет подтянуть прокси профиля из Dolphin — капча будет решаться с неверного IP, и регистрация/логин упадут.
    • Где взять: Dolphin Anty → Настройки → API (или на dolphin-anty.com → раздел API) → создать токен → скопировать длинную строку вида eyJ0eXAi....
    • ⚠️ Токен из шаблона конфига — placeholder и уже просрочен. Обязательно замените на свой свежий, иначе получите ошибки Dolphin.

Vision:

  • В конфиге: vision_config=имя_папки,API_ключ
  • Порт локального API: vision_port=53633 (по умолчанию 3030 — укажите порт вашего VisionM)

Afina:

  • В конфиге: afina_api_key=ваш_API_ключ и afina_port=50778 (порт по умолчанию)
  • API-ключ берётся из настроек Afina (Settings → API)
  • 🆔 [PROFILE] profile_id = Account ID (UUID вида 8e308a06-f9fd-4927-...) — колонка «Account ID» в Afina (рядом иконка копирования). НЕ имя профиля и НЕ колонка «ID» (там внутренний номер, API его не принимает). Нет колонки — правый верх → Columns → включить Account ID.
  • ♻️ Профиль переиспользуется между действиями автоматически (не перезапускается каждый раз). Чтобы он оставался открытым — close_after=NO. Логин/регистрация всегда стартуют с чистой сессии.

18. 🛡️ VPN для пилота: системный прокси

Заголовок раздела «18. 🛡️ VPN для пилота: системный прокси»

🩺 Боль пилотов: включили VPN — и прокси в антидетект-браузере перестали работать: профили не открываются, бесконечная загрузка, IP не тот. В режиме полного туннеля (TUN) через VPN идёт весь трафик системы, включая соединения антидетект-браузера с его собственными прокси, — и цепочка ломается.

Решение — режим «Системный прокси». VPN покрывает обычные приложения (Chrome, Telegram, терминал, AutoPilot.exe), а антидетект-браузеры продолжают ходить через прокси своих профилей: системный прокси на них не распространяется, пока вы сами не включите в антидетекте опцию «использовать системный прокси».

Шаг 1. Установите клиент INCY — Windows / macOS / Linux (есть и Android): GitHub → Releases

ОСФайл
🪟 Windowsincy-windows-setup.exe (или incy-windows-portable.zip)
🍎 macOSincy-macos-arm64.dmg (Apple Silicon) / incy-macos-intel.dmg (Intel)
🐧 Linuxincy-linux-x64.deb / incy-linux-x64.rpm / incy-linux-x64-portable.zip

Шаг 2. Добавьте свою VLESS-подписку. Нужна ссылка-подписка от VPN-провайдера — рекомендуем BlancVPN (VLESS + Reality, ~50 серверов, 45 стран): оформить подписку → — по этой ссылке вы получаете 1 бесплатный месяц и скидку в подарок. Скопируйте ссылку подписки, откройте INCY и нажмите «Вставить» (или «+ Добавить») — список серверов подтянется сам.

Шаг 3. Настройки → Соединение → включите «LAN через прокси».

Этот переключатель распространяет VLESS-прокси на локальные приложения — на терминал, а значит и на сам AutoPilot.exe.

Шаг 4. Главная → выберите режим «Системный прокси» и нажмите кнопку включения.

Что получится в итоге:

ТрафикИдёт через
Chrome, Telegram, терминал, AutoPilot.exeVPN (ваша VLESS-подписка)
AdsPower / Dolphin / Vision / Afinaпрокси профиля — как и раньше

🔌 Если не грузится сам антидетект (панель не открывается, лицензия/API недоступны в вашей сети) — уведите через системный прокси служебный трафик самой программы. В Afina: Network Detection → «Use system proxy for connection», там же кнопки Detect system proxy и Test via system proxy. Через прокси пойдёт только трафик приложения (API, отпечатки, лицензия) — прокси профилей остаются нетронутыми.

⚠️ Не включайте TUN, если работаете с антидетект-браузерами — именно полный туннель ломает прокси профилей. Для AutoPilot нужен режим «Системный прокси».
