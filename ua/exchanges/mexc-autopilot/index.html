Забудьте про ручну роботу: рішення знайдено

Section titled “Забудьте про ручну роботу: рішення знайдено”

Ручне керування акаунтами потребує багато часу, зусиль і пов’язане з ризиком помилок. Для масштабування своїх операцій вам необхідно:

  • Регулярно виконувати однотипні дії
  • Оптимізувати час

AutoPilot Software вирішує ці проблеми, перетворюючи рутину на автоматичний процес. Інтеграція з AdsPower & Dolphin забезпечує захист цифрових відбитків та безпечну роботу з багатьма акаунтами.

Як працює AutoPilot

Section titled “Як працює AutoPilot”

Основні переваги

Section titled “Основні переваги”

Економія часу: Автоматизація дозволяє одночасно керувати сотнями акаунтів

Зручність у використанні: Займайтесь своїми справами поки AutoPilot автоматизує дії у фоновому режимі. Ви можете користуватися своїми додатками поки AutoPilot працює у вікнах браузера на задньому фоні

Інтеграція з AdsPower / Dolphin / Vision / Afina: Безпечне та анонімне використання акаунтів. AutoPilot автоматично запускає та інтегрується у створену антидетект сесію браузера з унікальними відбитками. AutoPilot не важливо відкриті профілі вже чи вони закриті — він почне автоматизувати процес у будь-якому випадку

Паралельна автоматизація: Автоматизуйте безліч акаунтів одночасно

Зручна таблиця обліку акаунтів: Ведіть облік усіх акаунтів в одній Excel таблиці. Можна додавати нові стовпці, змінювати порядок стовпців на свій розсуд, головне не змінювати назви стовпців з шаблону

Налаштування режиму автоматизації — унікальні режими швидкості:

  • FAST — максимально швидка робота з мінімальними затримками
  • MEDIUM — середня швидкість, імітація людської поведінки, Smart Cursor, Human Typing
  • SLOW — повільна швидкість, повна імітація людської поведінки

Мультифункціональність: Налаштуйте будь-які дії для кожного акаунта. Наприклад, AutoPilot буде отримувати адресу депозиту для одних акаунтів, а на інших буде виводити кошти

Автоматичні ланцюжки дій: Обирайте будь-яку дію — AutoPilot автоматично увійде в акаунт, якщо потрібен вхід. Також сам увімкне 2FA захист, якщо він ще не підключений

Функціонал MEXC AutoPilot

Section titled “Функціонал MEXC AutoPilot”

AutoPilot підтримує безліч автоматизованих дій для MEXC:

  • Реєстрація акаунтів на MEXC: звичайним методом, за реферальним посиланням
  • Логін: вхід в акаунт, перевірка верифікації та балансу
  • Перевірка KYC: перевірка рівня верифікації
  • Керування 2FA: підключення двофакторної автентифікації та введення кодів
  • Отримання адреси депозиту для кожного акаунта
  • Виведення коштів з акаунта
  • Додавання адрес у whitelist з підтримкою різних мереж
  • Отримання API-ключів для торгівлі з налаштуванням дозволів
  • Автоматичний трейдинг: торгівля та набивання об’єму у вказаних парах
  • Послідовна торгівля: підтримка кількох монет через кому
  • Розумні ф’ючерси: відкриття по ринку з автоматичним стоп-лоссом і утриманням позиції
  • Автоматичне вирішення капчі, отримання кодів верифікації та багато іншого

🧩 Налаштування капчі

Section titled “🧩 Налаштування капчі”

Капчу AutoPilot вирішує сам, всередині exe — безкоштовно, без сторонніх сервісів і без браузера. Для більшості капч на MEXC платний ключ не потрібен: софт стартує і працює без нього.

Платний провайдер підключається лише як підстраховка на рідкісні типи капчі. Якщо вирішите завести ключ — підходять три сервіси:

  • ⭐ CapSolver — capsolver.com — рекомендовано
  • CapMonster — capmonster.cloud
  • 2Captcha — 2captcha.com

Налаштовується в AutoPilot.config:

🏠 Проксі профілю обов’язково має бути резидентським — вбудований вирішувач надсилає перевірку капчі з IP профілю, а датацентрові IP не проходять. Детальніше — FAQ → секція 4: Проксі та капча.

futures_mx — Розумні ф’ючерси (ринок + стоп-лосс)

Section titled “futures_mx — Розумні ф’ючерси (ринок + стоп-лосс)”

Відкриття ф’ючерсної позиції по ринку з автоматичним стоп-лоссом за один виклик. Позиція тримається до спрацювання стопа — без тейк-профіту і без зворотного закриття.

ПараметрДе задаєтьсяОпис
Потребує[TRADING] trading_coin (Excel)Пара (наприклад: SOL_USDT або SOL) — єдиний параметр на профіль
Потребуєleverage (конфіг)Кредитне плече (наприклад: 15)
Потребуєfutures_position_size (конфіг)Розмір у % від ф’ючерсного балансу USDT (як маржа). Наприклад: 25
Потребуєtp_sl_percentages (конфіг)TP,SL у % — дія бере SL (2-ге число). 💡 Для хеджу рекомендуємо 5,5 (SL 5%) — дає позиції ~95% запасу ходу, щоб хедж дожив до кінця і його не вибило завчасно
Опціональноfutures_side (конфіг)Напрямок: long (за замовч.) / short
Опціональноfutures_margin_mode (конфіг)Режим маржі: cross (за замовч.) / isolated
Оновлює[MEXC_FUTURES] order_idID відкритого ордера
Оновлює[RESULT] statusЗаписує яка угода відкрита — наприклад [MEXC_FUTURES] SUCCESS - LONG SOL_USDT 5cont 10x SL@142.30 ~75.00USDT id=... (напрямок / монета / контракти / плече / стоп / об’єм), або причина помилки. Видно прямо в стовпці статусу — не заплутаєшся.

Єдиний конфіг — жодних нових стовпців. Усі параметри, крім монети, беруться зі спільного файлу конфігурації (ті самі ключі, що й у ф’ючерсних дій Bybit). На профіль в Excel задається лише монета.

Відкриття по ринку, а не ліміткою. На MEXC комісія ф’ючерсів = 0, маркет-ордер зараховує торговий об’єм і входить миттєво.

🛡️ Ідеально для хеджу. Хедж відкривається проти позиції на іншій біржі (основна позиція там — тут, на MEXC, ти відкриваєш протилежну сторону: futures_side=short проти лонга, long проти шорта), i ціновий ризик перекрито. Чому заходить: вхід по ринку миттєвий, комісія = 0, авто-стоп сам обмежує збиток, позиція тримається без нагляду до стопа, а розмір у % від балансу дає однаковий хедж одразу на всіх профілях. Чому SL 5%: дає хеджу ~95% запасу ходу — позиція доживає до кінця, її не вибиває завчасно. Рекомендований старт: leverage=10, futures_position_size=20, tp_sl_percentages=5,5.

Розмір позиції (futures_position_size) — це % від доступного ф’ючерсного балансу USDT, використовується як маржа. Розмір позиції = маржа × плече. Приклад: баланс 100 USDT, futures_position_size=25, leverage=15 → маржа 25 USDT, позиція ~375 USDT.

Стоп-лосс береться з tp_sl_percentages (2-ге число = SL) i рахується від руху ціни: для long стоп = вхід × (1 − SL/100), для short = вхід × (1 + SL/100). Без SL позиція відкривається без стопа.

Утримання. Зворотного закриття немає — позиція тримається скільки завгодно, доки не спрацює стоп.
