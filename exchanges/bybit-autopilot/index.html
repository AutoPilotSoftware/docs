Bybit AutoPilot

AutoPilot Software — Максимальная Автоматизация на Bybit

Заголовок раздела «AutoPilot Software — Максимальная Автоматизация на Bybit»

Поддержка AdsPower & Dolphin & Vision & Afina Windows / MacOS / Linux

Забудьте о ручной работе: решение найдено

Заголовок раздела «Забудьте о ручной работе: решение найдено»

Bybit — одна из ведущих криптовалютных бирж мира с возможностями для заработка через Airdrop, TokenSplash события и специальные ивенты.

Ручное управление аккаунтами требует много времени, усилий и сопряжено с риском ошибок. AutoPilot Software превращает рутину в автоматический процесс. Интеграция с AdsPower, Dolphin, Vision и Afina обеспечивает защиту цифровых отпечатков и безопасную работу с множеством аккаунтов.

Как работает AutoPilot

Заголовок раздела «Как работает AutoPilot»

Основные преимущества

Заголовок раздела «Основные преимущества»

Экономия времени: Автоматизация позволяет одновременно управлять сотнями аккаунтов

Удобство в использовании: Занимайтесь своими делами пока AutoPilot автоматизирует действия в фоновом режиме

Интеграция с AdsPower / Dolphin / Vision / Afina: Безопасное и анонимное использование аккаунтов. AutoPilot автоматически запускает и интегрируется в созданную антидетект сессию браузера с уникальными отпечатками

Параллельная автоматизация: Автоматизируйте множество аккаунтов одновременно

Удобная таблица учета аккаунтов: Ведите учет всех аккаунтов в одной Excel таблице. Можно добавлять новые столбцы, менять порядок для себя — главное не менять название столбцов из шаблона

Режимы скорости:

  • FAST — максимально быстрая работа с минимальными задержками
  • MEDIUM — средняя скорость, имитация человеческого поведения, Smart Cursor, Human Typing
  • SLOW — медленная скорость, полная имитация человеческого поведения

Мультифункциональность: Настройте любые действия для каждого аккаунта. Например, AutoPilot будет получать адрес депозита для одних аккаунтов, а на других — выводить средства

Автоматические цепочки действий: Выбирайте любое действие — AutoPilot автоматически зайдет в аккаунт, если требуется вход. Также сам включит 2FA защиту, если она еще не подключена

Автогенерация паролей: При регистрации AutoPilot сгенерирует надёжный пароль, если он не указан

Полная продажа активов: Полный вывод с автоматической конвертацией всех активов в USDT

Логирование: Полное логирование результатов в logs/ и автоматические бэкапы таблицы в backup/

Функционал Bybit AutoPilot

Заголовок раздела «Функционал Bybit AutoPilot»

AutoPilot поддерживает широкий набор автоматических действий для Bybit:

  • Регистрация аккаунтов на Bybit: обычным методом, по реферальной ссылке
  • Логин: вход в аккаунт, проверка верификации и баланса
  • Проверка KYC: проверка уровня верификации с отображением страны, имени, документа
  • Управление 2FA: подключение двухфакторной аутентификации
  • Обучение и аватар: прохождение обучающих модулей и установка аватара профиля
  • Получение адреса депозита для каждого аккаунта
  • Добавление адресов в whitelist с поддержкой различных сетей
  • Вывод средств с аккаунта, включая полный вывод с конвертацией всех активов
  • Получение API-ключей для торговли
  • Автоматический трейдинг: маркет и лимитная торговля, набив объёма в указанных парах
  • Покупка / Продажа: покупка активов и продажа всех монет в USDT
  • Фьючерсная торговля: стандартные и умные фьючерсы с post-only ордерами (экономия 32% на комиссиях)
  • Стейкинг: USDT Flexible Savings (earn / unearn)
  • TokenSplash: автоматическое участие в ивентах с выполнением задач на депозит
  • LaunchPad: автоматическая регистрация в активных LaunchPad ивентах
  • Puzzle Hunt: автоматическое прохождение puzzle-задач
  • Реферальные коды: автоматическое извлечение реферальных кодов аккаунтов
  • KYC ссылка: получение ссылки SUMSUB верификации
  • Подсчёт прибыли: автоматический анализ WITHDRAW − DEPOSIT − P2P-закуп + баланс
  • Автоматическое решение капчи, получение кодов верификации и многое другое

Полный список действий (ACTION)

Заголовок раздела «Полный список действий (ACTION)»

➕ Несколько действий за один проход. В ячейку ACTION можно записать цепочку через + — например register+learn+whitelist. Шаги выполняются по очереди на каждом аккаунте, браузер профиля между ними не перезапускается. Подробнее — FAQ → Цепочки действий.

Общая схема работы действий

Заголовок раздела «Общая схема работы действий»

Все действия кроме регистрации автоматически зайдут в аккаунт, если требуется. Действия whitelist и withdraw автоматически подключат 2FA, если не установлен.

Мастер-кошелёк — Авто-whitelist, $0 комиссий, неотслеживаемый вывод

Заголовок раздела «Мастер-кошелёк — Авто-whitelist, $0 комиссий, неотслеживаемый вывод»

Выводите с сотен аккаунтов не вводя ни одного адреса вручную. AutoPilot создаёт уникальный кошелёк для каждого аккаунта, сам добавляет его в whitelist, выводит с нулевой комиссией и собирает всё на ваш мастер-кошелёк. Каждый аккаунт выводит на свой адрес — связать их между собой невозможно.

setup_aptos_hd — Создание мастер-кошелька

Заголовок раздела «setup_aptos_hd — Создание мастер-кошелька»

Запускается один раз. Создаёт ваш мастер-кошелёк и показывает секретную фразу (12 слов). Сохраните её — она контролирует все ваши адреса.

ПараметрСтолбецОписание
ТребуетсяКонфиг: activation_keyПароль шифрования
РезультатФайл: aptos_master_seed.encЗашифрованная секретная фраза

⚠️ Сохраните секретную фразу! Показывается один раз. Потеряли фразу = потеряли доступ ко всем адресам и средствам.

whitelist_aptos_hd — Автоматический whitelist

Заголовок раздела «whitelist_aptos_hd — Автоматический whitelist»

Запускается на всех профилях. Для каждого аккаунта AutoPilot:

  1. Создаёт уникальный Aptos-адрес (разный для каждого аккаунта)
  2. Заходит на Bybit, добавляет его в whitelist
  3. Подтверждает email/2FA — полностью автоматически
  4. Сохраняет всё в таблицу

Никакой ручной работы. Не нужно создавать кошельки, копировать адреса или заполнять таблицу.

ПараметрСтолбецОписание
Автосоздание[WHITELIST] whitelist_addressУникальный Aptos-адрес
Автоустановка[WHITELIST] whitelist_networkAPTOS
Обновляет[RESULT] status[WHITELIST_HD] SUCCESS

🔁 Можно перезапускать: уже есть адрес? AutoPilot использует его — дубликатов не будет.

Сбор средств: вкладка Distribute

Заголовок раздела «Сбор средств: вкладка Distribute»

После вывода USDT лежат на индивидуальных адресах. Откройте вкладку Distribute в десктоп-приложении:

  • Выбрать профили → Просмотреть → Один клик → Всё собрано на мастер-кошелёк
  • Газ: ~0.002 APT на профиль (доли цента)
  • Работает в обе стороны: сбор с аккаунтов или раздача на них

Почему Aptos?

СетьКомиссия BybitСкорость
Aptos$0~1 сек
Arbitrum$0.1~1 сек
TRC20$1~3 мин
ERC20$1-5~5 мин

💰 Чем больше аккаунтов — тем больше экономите. Каждый вывод через TRC20/ERC20 стоит $1-5. Через Aptos = $0.

🕵️ Приватность: каждый аккаунт → свой адрес → общих адресов нет → связать аккаунты между собой невозможно.

trading — Автоматический трейдинг

Заголовок раздела «trading — Автоматический трейдинг»

Торговля и набив объёма маркет ордерами с поддержкой нескольких монет

ПараметрСтолбецОписание
Требует[TRADING] trading_coinАктив для торговли (например: BTC или BTC,ETH,SOL)
Требует[TRADING] trading_amountРазмер ордера в USDT (например: 10 или 10,20,5)
Требует[TRADING] trading_cyclesКол-во циклов покупки-продажи (например: 3 или 3,5,2)
Обновляет[RESULT] status[TRADING] VOLUME: объём, FEES: комиссии

Мульти-монеты: укажите через запятую несколько монет, размеров и циклов — AutoPilot будет торговать ими последовательно. Пример: BTC,ETH + 10,20 + 3,5 = 3 цикла BTC по 10 USDT, затем 5 циклов ETH по 20 USDT

Формула объёма: циклы × размер ордера × 2 (покупка + продажа) Пример: 3 цикла по 10 USDT = 3 × 10 × 2 = 60 USDT объёма

ts — TokenSplash

Заголовок раздела «ts — TokenSplash»

Автоматическое участие в TokenSplash ивентах на Bybit. Действие идёт в два шага: регистрация в ивенте и (опционально) выполнение задачи на торговлю.

ПараметрСтолбецОписание
Требует[TS] codeКод ивента (из ссылки …/token-splash/detail?code=)
Обновляет[RESULT] statusСтатус регистрации/задачи (см. ниже)

Как это работает

Заголовок раздела «Как это работает»
  1. Регистрация (участие). Пилот при необходимости сам логинится, проверяет KYC и нажимает «Участвовать» через API биржи. Баланс для этого не нужен — даже аккаунт с 0 USDT будет зарегистрирован в ивенте.
  2. Задача на торговлю (управляется конфигом ts_order). Если на аккаунте есть USDT, пилот покупает токен ивента и тут же продаёт его (1 покупка + 1 продажа маркет-ордерами) — это закрывает «задачу на депозит» ивента. Размер каждого ордера — случайное число между двумя значениями ts_order.

Зависимость от баланса

Заголовок раздела «Зависимость от баланса»
  • Нет / 0 USDT → пилот только регистрируется в ивенте. Если зарегистрироваться не удалось — пишет причину в таблицу.
  • Есть баланс (хватает на размер ордера; ~60 USDT с запасом) → после регистрации ещё и торгует купить/продать, чтобы закрыть задачу.

Чтобы аккаунты только регистрировались (без торговли), поставьте ts_order=0,0.

Настройка ts_order (в AutoPilot.config)

Заголовок раздела «Настройка ts_order (в AutoPilot.config)»
  • ts_order=50,55 → каждый ордер случайный 50–55 USDT (купить на ~50–55 и продать — задание на торговлю закрыто).
  • ts_order=0,0 → задачу на торговлю пропустить, только зарегистрироваться.
  • Комментарий (random 55-100) в дефолтном конфиге — просто пример; реальный размер берётся из ваших MIN,MAX.

learn — Прохождение обучения и установка аватара

Заголовок раздела «learn — Прохождение обучения и установка аватара»

Автоматическое «прогревание» аккаунта через раздел Bybit Learn: действие ставит случайный аватар профиля и проходит обучающие статьи, выполняя на каждой полный набор действий вовлечённости (лайк, просмотр, комментарий, добавление в избранное, репост). Это делает аккаунт более «живым» и засчитывает прогресс в кампании Bybit Learn — задания за комментарии и репосты статей приносят баллы и награды.

ПараметрСтолбецОписание
Требуетвход в аккаунтЕсли профиль не залогинен — действие само выполнит вход (логин + 2FA при необходимости); [LEARN] FAIL - CAN'T LOGIN только если автологин не удался
Обновляет[RESULT] status[LEARN] SUCCESS / [LEARN] PARTIAL / [LEARN] FAIL (см. ниже)

Что делает действие:

  • Аватар — берёт случайный аватар из галереи Bybit и ставит его профилю. Если аватар уже был установлен ранее (запоминается на сервере), шаг пропускается — повторный запуск не меняет аватар.
  • 5 случайных статей — из файла bybit_learn_links.txt (91 ссылка) случайно выбираются 5 статей за запуск. Домен ссылок автоматически подменяется на домен профиля (learn.bybit.com → learn.bybitglobal.com и т.п.).
  • На каждой статье последовательно выполняются: лайк → просмотр → комментарий (случайная фраза из 15) → в избранное (звезда) → репост. Комментарий и репост дополнительно засчитываются как задания кампании Learn для начисления наград.

Алгоритм работы

Заголовок раздела «Алгоритм работы»

Статусы в [RESULT] status:

  • [LEARN] SUCCESS - Avatar set, 5/5 articles — аватар установлен и пройдены все 5 статей.
  • [LEARN] PARTIAL - Avatar: YES/NO, N/5 articles — выполнено не всё: аватар не установился, либо одна из статей завершилась с ошибкой (счётчик пройденных статей падает до N < 5).
  • [LEARN] FAIL - ... — не удалось войти (CAN'T LOGIN), нет ссылок (NO LINKS IN FILE) или ошибка чтения файла (LINKS FILE ERROR).

Если на конкретной статье действия вовлечённости недоступны, лайк/комментарий/избранное/репост на ней пропускаются (засчитывается только просмотр), но статья всё равно считается пройденной — на статус SUCCESS это не влияет.

Файл bybit_learn_links.txt

Заголовок раздела «Файл bybit_learn_links.txt»

Держите файл bybit_learn_links.txt в папке с пилотом — рядом с AutoPilot.exe. Действие читает его при каждом запуске и берёт 5 случайных ссылок. Файл можно редактировать: добавляйте или убирайте ссылки на статьи learn.bybit.com; пустые строки и строки без http игнорируются.

Домен в ссылках подменяется автоматически под [BYBIT] domain профиля, поэтому в файле можно держать ссылки в формате learn.bybit.com — они сами перенаправятся на нужный региональный домен.

limit — Случайная лимитная торговля

Заголовок раздела «limit — Случайная лимитная торговля»

Автоматическая лимитная торговля с рандомизированными ордерами для естественного набива объёма.

⚠️ В отличие от остальных торговых действий, параметры для limit читаются из AutoPilot.config, а не из колонок [TRADING] Excel-таблицы.

Параметры из AutoPilot.config:

КлючОписаниеПример
Требует random_buy_listСписок монет через запятую. Для каждого запуска монета выбирается случайноrandom_buy_list=BTC,ETH
Требует random_buy_amountДиапазон размера ордера в USDT (мин,макс)random_buy_amount=10,15
Требует random_buy_sell_rangeДиапазон цены ордера на продажу в % выше текущей (мин,макс)random_buy_sell_range=6.7,7.2

Из Excel-таблицы используются только базовые колонки для входа: [PROFILE] profile_id, [PROFILE] mail, [PROFILE] bybit_password, [BYBIT] domain, [ACTION] action=limit. Колонки [TRADING] trading_coin/amount/cycles для этого действия не применяются.

Обновляет: [RESULT] status — отчёт вида [LIMIT] PLACED <кол-во> <монета>: <цена продажи> USDT (TOTAL: ...), SPENT: ... USDT

Требования к файлу конфигурации:

  • Имя файла — AutoPilot.config, расположен рядом с исполняемым файлом.
  • Строки с параметрами random_buy_* не должны начинаться с # — такие строки интерпретируются как комментарии.
  • Кодировка — UTF-8 без BOM.
  • Файл должен быть сохранён до запуска автоматизации.

Алгоритм работы

Заголовок раздела «Алгоритм работы»

Три источника случайности в одном запуске:

  1. Выбор монеты — из random_buy_list, исключая те, по которым уже есть открытые лимит-ордера на аккаунте. Это предотвращает дублирование позиций и обеспечивает равномерное распределение объёма.
  2. Размер BUY-ордера — случайное значение в USDT в диапазоне random_buy_amount (мин,макс). Например, 10,15 даёт любую сумму от 10 до 15 USDT с точностью, поддерживаемой инструментом (quotePrecision).
  3. Наценка на SELL — случайный процент в диапазоне random_buy_sell_range (мин,макс). Например, 6.7,7.2 ставит лимит-продажу на 6.7–7.2% выше текущей ask-цены.

Важные технические моменты:

  • Покупка выполняется рыночным ордером (type=market, side=buy), продажа — лимитным (type=limit, side=sell, time_in_force=gtc). Это даёт гарантированный быстрый вход по рынку и пассивный выход по цене с наценкой.
  • Точность цены продажи подстраивается под tickSize инструмента, точность количества — под basePrecision, точность суммы покупки — под quotePrecision (берётся из Bybit Market API /v5/market/instruments-info).
  • За один запуск действия размещается одна пара ордеров (один BUY + один SELL). Для набора объёма действие запускается повторно (через auto_loop или планировщик).
  • Если по всем монетам из random_buy_list уже стоят открытые лимит-ордера, действие завершится ошибкой All configured coins already have open orders без размещения новых ордеров.

Пример запуска

Заголовок раздела «Пример запуска»

Конфигурация:

Шаг за шагом, что произойдёт при запуске:

  1. Чтение конфига: список монет [BTC, ETH], диапазон суммы [10, 15] USDT, диапазон наценки [6.7, 7.2] %.
  2. Проверка открытых ордеров: запрос возвращает, что по BTC уже стоит один лимит-ордер на продажу. ETH свободна.
  3. Выбор монеты: из доступных [ETH] выбрана ETH. Торговая пара — ETHUSDT.
  4. Случайная сумма покупки: сгенерировано 12.43 USDT (любое число в диапазоне 10–15).
  5. MARKET BUY: выполнена покупка ETH на 12.43 USDT по текущей рыночной цене. Допустим, куплено 0.003212 ETH.
  6. Пауза 5 секунд на исполнение и обновление баланса.
  7. Запрос баланса: кошелёк показывает 0.003212 ETH (после комиссии).
  8. Текущая ask-цена ETH: допустим, 3870.50 USDT.
  9. Случайная наценка: сгенерировано 6.94 % (в диапазоне 6.7–7.2).
  10. Расчёт цены продажи: 3870.50 × (1 + 6.94/100) = 4139.17 USDT.
  11. LIMIT SELL: выставлен лимит-ордер на продажу 0.003212 ETH по цене 4139.17 USDT.
  12. Запись в таблицу: [RESULT] status = [LIMIT] PLACED 0.003212 ETH: 4139.17 USDT (TOTAL: 13.29), SPENT: 12.43 USDT.

При следующем запуске этого же действия AutoPilot снова проверит открытые ордера: если ETH-ордер всё ещё висит, будет выбрана BTC (если по BTC ордера уже нет). Таким образом действие чередует монеты из списка, не создавая по каждой больше одного открытого ордера одновременно.

🌐 Bybit Global домены

Заголовок раздела «🌐 Bybit Global домены»

Bybit использует несколько региональных доменов для разных юрисдикций. AutoPilot поддерживает выбор домена через столбец [BYBIT] domain в AutoPilot_table.xlsx.

Доступные значения:

Значение столбцаИтоговый доменКогда использовать
(пусто)bybit.comПо умолчанию
bybitglobalbybitglobal.comЕсли есть проблемы с регистрацией, 2FA или капчей

Как подключить:

  1. Добавьте столбец [BYBIT] domain в AutoPilot_table.xlsx
  2. Укажите bybitglobal для нужных профилей (или оставьте пустым для bybit.com)
  3. Запустите любое действие — AutoPilot автоматически перейдёт на выбранный домен

💡 Когда переключаться на bybitglobal:

  • Регистрация на bybit.com не проходит, а на bybitglobal.com работает
  • При подключении 2FA код на почту не приходит (актуально для Google Authenticator в ряде регионов)
  • Капча решается нестабильно на bybit.com
  • В некоторых регионах bybitglobal.com работает стабильнее в целом

⚠️ На заметку: bybit.com и bybitglobal.com — это отдельные региональные версии с раздельными аккаунтами. Профиль, зарегистрированный на одном домене, должен продолжать работать с тем же [BYBIT] domain — не переключайте домены для уже созданных аккаунтов.

Настройка почты (IMAP)

Заголовок раздела «Настройка почты (IMAP)»

AutoPilot использует протокол IMAP для получения кодов верификации с почты.

Поддерживаемые провайдеры: Yahoo, Rambler, iCloud, Outlook, Gmail, Mail.ru, First Mail и другие

Для Gmail, Outlook, Yahoo, iCloud требуется создание пароля приложения (App Password) — обычный пароль не подойдёт для IMAP. Либо настройте переадресацию писем на почту с прямым IMAP доступом.
