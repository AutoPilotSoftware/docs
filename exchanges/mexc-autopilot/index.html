Забудьте о ручной работе: решение найдено

Заголовок раздела «Забудьте о ручной работе: решение найдено»

Ручное управление аккаунтами требует много времени, усилий и сопряжено с риском ошибок. Для масштабирования своих операций вам необходимо:

  • Регулярно выполнять однотипные действия
  • Оптимизировать время

AutoPilot Software решает эти проблемы, превращая рутину в автоматический процесс. Интеграция с AdsPower & Dolphin обеспечивает защиту цифровых отпечатков и безопасную работу с множеством аккаунтов.

Как работает AutoPilot

Заголовок раздела «Как работает AutoPilot»

Основные преимущества

Заголовок раздела «Основные преимущества»

Экономия времени: Автоматизация позволяет одновременно управлять сотнями аккаунтов

Удобство в использовании: Занимайтесь своими делами пока AutoPilot автоматизирует действия в фоновом режиме. Вы можете использовать свои приложения пока AutoPilot работает в окнах браузера на заднем фоне

Интеграция с AdsPower / Dolphin / Vision / Afina: Безопасное и анонимное использование аккаунтов. AutoPilot автоматически запускает и интегрируется в созданную антидетект сессию браузера с уникальными отпечатками. AutoPilot не важно открыты ли профили уже или они закрыты — он начнет автоматизировать процесс в любом случае

Параллельная автоматизация: Автоматизируйте множество аккаунтов одновременно

Удобная таблица учета аккаунтов: Ведите учет всех аккаунтов в одной Excel таблице. Можно добавлять новые столбцы, менять порядок столбцов для себя по желанию, главное не менять название столбцов из шаблона

Настройка режима автоматизации — уникальные режимы скорости:

  • FAST — максимально быстрая работа с минимальными задержками
  • MEDIUM — средняя скорость, имитация человеческого поведения, Smart Cursor, Human Typing
  • SLOW — медленная скорость, полная имитация человеческого поведения

Мультифункциональность: Настройте любые действия для каждого аккаунта. Например, AutoPilot будет получать адрес депозита для одних аккаунтов, а на других будет выводить средства

Автоматические цепочки действий: Выбирайте любое действие — AutoPilot автоматически зайдет в аккаунт, если требуется вход. Также сам включит 2FA защиту, если она еще не подключена

Функционал MEXC AutoPilot

Заголовок раздела «Функционал MEXC AutoPilot»

AutoPilot поддерживает множество автоматизированных действий для MEXC:

  • Регистрация аккаунтов на MEXC: обычным методом, по реферальной ссылке
  • Логин: вход в аккаунт, проверка верификации и баланса
  • Проверка KYC: проверка уровня верификации
  • Управление 2FA: подключение двухфакторной аутентификации и ввод кодов
  • Получение адреса депозита для каждого аккаунта
  • Вывод средств с аккаунта
  • Добавление адресов в whitelist с поддержкой различных сетей
  • Получение API-ключей для торговли с настройкой разрешений
  • Автоматический трейдинг: торговля и набив объёма в указанных парах
  • Последовательная торговля: поддержка нескольких монет через запятую
  • Умные фьючерсы: открытие по рынку с автоматическим стоп-лоссом и удержанием позиции
  • Автоматическое решение капчи, получение кодов верификации и многое другое

🧩 Настройка капчи

Заголовок раздела «🧩 Настройка капчи»

Капчу AutoPilot решает сам, внутри exe — бесплатно, без сторонних сервисов и без браузера. Для большинства капч на MEXC платный ключ не нужен: софт стартует и работает без него.

Платный провайдер подключается только как подстраховка на редкие типы капчи. Если решите завести ключ — подходят три сервиса:

  • ⭐ CapSolver — capsolver.com — рекомендуется
  • CapMonster — capmonster.cloud
  • 2Captcha — 2captcha.com

Настраивается в AutoPilot.config:

🏠 Прокси профиля обязан быть резидентским — встроенный решатель отправляет проверку капчи с IP профиля, а датацентровые IP не проходят. Подробнее — FAQ → секция 4: Прокси и капча.

Заголовок раздела «trading_mx — Автоматический трейдинг»

Торговля и набив объёма маркет ордерами с поддержкой нескольких монет

ПараметрСтолбецОписание
Требует[TRADING] trading_coinАктив для торговли (например: BTC или BTC,ETH,SOL)
Требует[TRADING] trading_amountРазмер ордера в USDT (например: 10 или 10,20,5)
Требует[TRADING] trading_cyclesКол-во циклов покупки-продажи (например: 3 или 3,5,2)

Мульти-монеты: укажите через запятую несколько монет, размеров и циклов — AutoPilot будет торговать ими последовательно. Пример: BTC,ETH + 10,20 + 3,5 = 3 цикла BTC по 10 USDT, затем 5 циклов ETH по 20 USDT

Формула объёма: циклы × размер ордера × 2 (покупка + продажа) Пример: 3 цикла по 10 USDT = 3 × 10 × 2 = 60 USDT объёма

futures_mx — Умные фьючерсы (рынок + стоп-лосс)

Заголовок раздела «futures_mx — Умные фьючерсы (рынок + стоп-лосс)»

Открытие фьючерсной позиции по рынку с автоматическим стоп-лоссом за один вызов. Позиция держится до срабатывания стопа — без тейк-профита и без обратного закрытия.

ПараметрГде задаётсяОписание
Требует[TRADING] trading_coin (Excel)Пара (например: SOL_USDT или SOL) — единственный параметр на профиль
Требуетleverage (конфиг)Кредитное плечо (например: 15)
Требуетfutures_position_size (конфиг)Размер в % от фьюч-баланса USDT (как маржа). Например: 25
Требуетtp_sl_percentages (конфиг)TP,SL в % — действие берёт SL (2-е число). 💡 Для хеджа рекомендуем 5,5 (SL 5%) — даёт позиции ~95% запаса хода, чтобы хедж дожил до конца и его не выбило раньше времени
Опциональноfutures_side (конфиг)Направление: long (по умолч.) / short
Опциональноfutures_margin_mode (конфиг)Режим маржи: cross (по умолч.) / isolated
Обновляет[MEXC_FUTURES] order_idID открытого ордера
Обновляет[RESULT] statusЗаписывает какая сделка открыта — например [MEXC_FUTURES] SUCCESS - LONG SOL_USDT 5cont 10x SL@142.30 ~75.00USDT id=... (направление / монета / контракты / плечо / стоп / объём), или причина ошибки. Видно прямо в столбце статуса — не запутаешься.

Единый конфиг — никаких новых столбцов. Все параметры, кроме монеты, берутся из общего файла конфигурации (те же ключи, что у фьючерсных действий Bybit). На профиль в Excel задаётся только монета.

Открытие по рынку, а не лимиткой. На MEXC комиссия фьючерсов = 0, маркет-ордер засчитывает торговый объём и входит мгновенно.

🛡️ Идеально для хеджа. Хедж открывается против позиции на другой бирже (основная позиция там — здесь, на MEXC, ты открываешь противоположную сторону: futures_side=short против лонга, long против шорта), и риск по цене перекрыт. Почему заходит: вход по рынку мгновенный, комиссия = 0, авто-стоп сам ограничивает убыток, позиция держится без присмотра до стопа, а размер в % от баланса даёт одинаковый хедж сразу на всех профилях. Почему SL 5%: даёт хеджу ~95% запаса хода — позиция доживает до конца, её не выбивает раньше времени. Рекомендуемый старт: leverage=10, futures_position_size=20, tp_sl_percentages=5,5.

Размер позиции (futures_position_size) — это % от доступного фьючерсного баланса USDT, используется как маржа. Размер позиции = маржа × плечо. Пример: баланс 100 USDT, futures_position_size=25, leverage=15 → маржа 25 USDT, позиция ~375 USDT.

Стоп-лосс берётся из tp_sl_percentages (2-е число = SL) и считается от движения цены: для long стоп = вход × (1 − SL/100), для short = вход × (1 + SL/100). Без SL позиция открывается без стопа.

Удержание. Обратного закрытия нет — позиция держится сколько угодно, пока не сработает стоп.

⚠️ Аккаунты под риск-контролем MEXC (сообщение «Position opening is unavailable…», код 6026) не могут открывать позиции до прохождения верификации — действие сообщит об этом в статусе.
